# Support policy

P2pKit is maintained on a best-effort open-source basis. For reproducible bugs,
use the GitHub bug-report form and include the P2pKit version, platform/OS,
minimal reproduction, expected/actual behavior, and sanitized logs.

Use discussions in an existing issue for scoped implementation questions. The
project does not promise response times, commercial support, product-specific
integration design, or debugging of private infrastructure.

Do not use public support channels for vulnerabilities; follow
[SECURITY.md](SECURITY.md). Review the [documentation](docs/README.md) and
[sample guide](docs/guides/samples.md) before filing a question.
