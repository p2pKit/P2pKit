## Root cause and corrected behavior

Symmetric encoder/decoder tests miss coordinated format changes. Existing independent Cacophony vectors,
preface/version guards and one-direction kit-level profile rejection refute the historical claim that no such
coverage existed; they did not cover the composed-session/envelope covariance gap.

Twelve immutable synthetic `.hex` resources now pin composed secure-channel transcripts and four envelope variants.
Tests replay each handshake role through the real secure implementation, asserting authorization inputs, identities,
fingerprint, handshake hash, HELLO/messages and every outbound byte with fragmented/coalesced reads. Envelope encoding
and fixed-byte decoding are checked separately. Both repeated mixed-profile kit directions must fail with typed
non-timeout errors, publish no application/session data, perform no fallback/redial and clean up without warnings.
Four Android-source host wrappers supplement common JVM/Native tests. See the [fixture guide](../../../testing/wire-goldens.md).

The commonTest-only transcriber reads committed bytes, never the current production encoder. AGP9.3's file-only
copy of KMP roots lost lint producer ownership; public variant registration did not fix those inputs. Both actual
host lint consumers now have lazy, true dependencies on `generateWireGoldens`, not ordering hints. Missing/empty
sets and malformed hex fail generation; a missing required individual filename fails its consuming test.

**#133 changes no production/API/ABI/wire/security behavior.** #355 is a distinct runtime fix. Synthetic fixed keys
are public test inputs, not credentials. Fixture capture used a temporary test at the stated unchanged baseline;
it was not a released-version certification or independent implementation.
