## RPC Host trust refresh

`RpcHost.reloadTrustFromStore()` reads the complete committed Host client set
from the configured durable store. Removed peers lose admission and their
connections close. Retained peers keep their authenticated connections and
application scopes. Additions can connect after reconciliation succeeds.
Store, validation, and retirement failures seal admission and close the Host.
The application owns device approval, login authorization, and coordination
with external writers. [Contract and example](../rpc/security-and-deployment.md#refresh-host-trust-after-an-external-commit).
